## Review Process

1. **Trigger:** Knowledge Manager opens a GitHub Issue at the start of the review period tagged `quarterly-review`.
2. **Review:** Document owner reviews content for accuracy and completeness.
3. **Update:** Owner updates `last_reviewed` in front matter, edits content if needed, and submits a PR.
4. **Approval:** Knowledge Manager merges the PR after review.
5. **Completion:** Owner closes the review Issue with a comment confirming completion.
