# Decorate Singing Cake

## Purpose

Decorate a custom singing cake accurately according to the customer's Order Oracle ticket, and load the correct melody before handoff.

## Audience

Apprentice Bakers assigned to the decoration station. Shift Lead must confirm melody loading before customer handoff for all custom orders.

## Prerequisites

- Cake layers are fully baked and cooled to room temperature.
- Order Oracle ticket is open and all specifications are confirmed.
- Melody stone matching the ticket song code is retrieved from the melody cabinet.
- Frosting colors and decoration supplies are stocked.

---

## Steps

### 1. Review the Order Ticket

1. Open Order Oracle. Locate the customer order by order number or customer name.
2. Confirm all order details:
   - Cake flavor and size.
   - Frosting color and decoration notes.
   - Melody song code (e.g., `SONG-042 — The Goblin Birthday Hum`).
   - Pickup date and time.
   - Any allergen or charm restriction flags.
3. If any detail is missing or unclear, contact the customer via the number on file before proceeding.

### 2. Crumb Coat and First Frost

1. Apply a thin crumb coat of frosting to seal the cake layers.
2. Refrigerate for 15 minutes to set the crumb coat.
3. Apply the final frosting layer in the customer's requested color. Use a straight-edge spatula for smooth sides.

### 3. Decoration

1. Apply decorations per the ticket notes (piped borders, fondant figures, edible glitter, etc.).
2. Pipe the customer's requested text on the top. Double-check spelling against the Order Oracle ticket.
3. Place the melody stone mount (a small charm socket) in the center of the cake base.

### 4. Melody Stone Loading

> **Important:** Load the melody stone last, after all decoration is complete. Early loading can cause the stone to activate during decoration, disrupting the bakery.

1. Retrieve the melody stone from the melody cabinet using the code from the Order Oracle ticket.
2. Verify the stone label matches the ticket: song title, song code, and duration.
3. Press the stone firmly into the charm socket on the cake base until you hear one soft chime. This confirms contact.
4. Test: light a test candle within 3 inches of the cake. The melody should begin within 5 seconds.
5. Blow out the test candle. The melody should stop within 3 seconds.

### 5. Quality Check

1. Verify the melody plays the correct song (not a substitute or prior customer's song).
2. Confirm the text matches the order.
3. Confirm frosting color matches the ticket.
4. If melody is incorrect: see [Exception: Wrong Melody] below.

### 6. Packaging and Ticket Update

1. Place the cake in the custom order box. Attach the Order Oracle ticket label to the outside.
2. Include the Singing Cake Care Card in the box (found in the supply drawer).
3. In Order Oracle, update the order status to **Ready for Pickup**.
4. Notify the Shift Lead that the order is complete and request melody confirmation sign-off.
5. Place in the designated custom order pickup shelf.

---

## Exception: Wrong Melody

If the melody stone plays the wrong song after loading:

1. Do not hand off the cake to the customer.
2. Remove the stone from the charm socket.
3. Return the incorrect stone to the melody cabinet and retrieve the correct one.
4. Re-test before re-packaging.
5. If the correct stone is not in the melody cabinet, notify the Shift Lead. The Shift Lead will contact the customer to arrange an alternate pickup time.

## Common Mistakes

- Loading the melody stone before decoration is complete.
- Using the wrong song code (always verify against the Order Oracle ticket, not from memory).
- Forgetting to update Order Oracle to "Ready for Pickup" before shelf placement.
- Skipping the melody test before packaging.

## Escalation Path

- Melody stone not available: Shift Lead.
- Order details unclear and customer cannot be reached: Shift Lead.
- Customer complaint about wrong song at pickup: apply [`customer-apology-scripts.md`](../job-aids/customer-apology-scripts.md), then escalate to Shift Lead.
