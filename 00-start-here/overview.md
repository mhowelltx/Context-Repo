# Knowledge Base Overview

Welcome to the **Grumble & Crumb Goblin Bakery Operations Manual** — the central knowledge base for all bakery operations, policies, training, and reference content.

## What This Repository Is

This repository is a structured, version-controlled knowledge base. It stores the authoritative documentation for how Grumble & Crumb operates. Every document here has a defined owner, a review schedule, and a clear status.

It is designed to be used by:
- **Employees** looking up procedures, policies, and answers to daily questions.
- **Shift Leads** managing escalations and quality.
- **Trainers** onboarding new associates.
- **AI agents** answering employee questions in real time.

## What This Repository Is Not

- It is not a place to store customer records, financial data, or personal information.
- It is not a substitute for real-time judgment in a safety-critical situation.
- It is not a legal or regulatory compliance system.
- Archived documents in `05-archive/` are not authoritative and should not be used for active operations.

## How Documents Are Organized

Content is organized by type and audience:

| Folder | What You'll Find |
|---|---|
| `00-start-here/` | How to navigate, agent rules, glossary |
| `01-business-units/` | Day-to-day procedures, policies, job aids, systems, FAQs |
| `02-shared-knowledge/` | Enterprise standards that apply to all roles |
| `03-training-content/` | Onboarding, role training, scenarios, assessments |
| `04-reference/` | Lookup tables, codes, statuses, forms |
| `05-archive/` | Outdated documents — for historical reference only |
| `90-templates/` | Blank templates for new documents |
| `99-admin/` | Content management, ownership, review scheduling |

## Document Quality Standards

Every active document in this repository:
- Has YAML front matter with status, owner, and review date.
- Is written clearly enough for a first-week associate to follow.
- Has been reviewed within the current review cycle.
- Links to related documents where relevant.
